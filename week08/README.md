# Week 08

## Overview
This folder contains Week 08 inheritance and application activities for MSE800.

## Contents
- `activity3`: Single inheritance flight system activity.
- `activity4`: Hybrid or hierarchical inheritance flight system activity.
- `car_rental`: Python, SQLite, and Docker car rental system.

## How to Run
Open the activity folder and run the relevant `main.py` or Python file. For the Docker activity, follow the README inside `car_rental`.

## Requirements
- Python 3
- Docker for the car rental activity
- diagrams.net or image viewer for class diagrams

## Notes
Inheritance activity READMEs should name the inheritance type, identify the parent and child classes, and explain how to run the demonstration.
