# Week 05

## Overview
This folder contains Week 05 diagram activities for MSE800.

## Contents
- `week5activity1.drawio.png`: Exported Draw.io diagram image.
- `week5activity4.drawio`: Editable Draw.io diagram file.

## How to View or Edit
Open the PNG file in an image viewer. Open the `.drawio` file in diagrams.net or the Draw.io extension for VS Code.

## Requirements
- Browser or image viewer
- diagrams.net or Draw.io extension for editing

## Notes
Diagram READMEs should explain which file is editable and which file is the exported version for viewing.
