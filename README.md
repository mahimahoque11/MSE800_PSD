# MSE800 PSD Coursework

## Overview
This repository contains weekly coursework and activities for MSE800 PSD. The work is organised by week so each activity can be reviewed separately.

## Folder Structure
- `week01`: Introductory Python and Jupyter notebook activity.
- `week02`: Python activities and assessment notes.
- `week03`: Activity diagrams and image outputs.
- `week04`: Use case diagrams, Python class activity, and database assessment.
- `week05`: Draw.io diagram activities.
- `week06`: Python application projects.
- `week07`: Design pattern and system design activities.
- `week08`: Inheritance activities and car rental application.
- `week09`: PDF activity submissions.
- `week10`: User authentication application and screenshot evidence.

## Requirements
- Python 3
- JupyterLab or another notebook viewer for `.ipynb` files
- SQLite or DB Browser for SQLite for database activities
- diagrams.net or Draw.io extension for `.drawio` files
- Docker for activities that include a `Dockerfile`

Python package dependencies are listed in:

```bash
requirements.txt
```

Some activity folders also include their own `requirements.txt` files.

## How to Use
Open the relevant week folder and read its `README.md` for activity-specific details. Python activities can usually be run from their own folder with:

```bash
python main.py
```

For notebook activities, open the `.ipynb` file in JupyterLab, Jupyter Notebook, or VS Code.

## Repository Notes
Generated files such as Python cache folders, notebook checkpoints, temporary files, and local testing output are ignored through `.gitignore`.
