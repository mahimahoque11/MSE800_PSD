# Demo: Design Patterns

## Overview
This folder contains Python examples of common object-oriented design patterns.

## Contents
- `Demo/adapter_pattern.py`: Adapter pattern example.
- `Demo/builder_pattern.py`: Builder pattern example.
- `Demo/factory_pattern.py`: Factory pattern example.
- `Demo/observer_pattern.py`: Observer pattern example.
- `Demo/singleton_pattern.py`: Singleton pattern example.

## How to Run
From this folder, run one pattern file at a time. For example:

```bash
python Demo/adapter_pattern.py
```

## Requirements
- Python 3

## Notes
The README should state the pattern being demonstrated, where the example file is located, and how to execute it for testing or review.
