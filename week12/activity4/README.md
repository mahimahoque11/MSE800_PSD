# Week 12 Activity 4 - Flask Image Upload

This activity creates a Flask web application that allows users to load an image from the local system and display it on the web page.

## Features

- Upload an image using a file input
- Save the uploaded image in `static/uploads`
- Display the uploaded image on the page
- Limit uploads to common image file types

## Requirements

- Python 3.12 or later
- Flask

Install the required package:

```bash
pip install -r requirements.txt
```

## Run the App

From this folder, run:

```bash
python app.py
```

Open the app in a browser:

```text
http://127.0.0.1:5000
```

Choose an image from your computer, click **Upload Image**, and the image will appear on the page.
