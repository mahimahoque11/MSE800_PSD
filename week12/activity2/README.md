# Week 12 Activity 2 - Flask Link Page

This activity creates a simple Flask web page with:

- A web page title
- A `Flask Quickstart` heading
- A link to the Flask Quickstart documentation using the HTML `<a>` tag
- Inline CSS that sets the page background color to green
- Inline CSS that sets the page text color to red
- CSS that changes the `Flask Quickstart` heading font style

## Requirements

- Python 3.12 or later
- Flask

Install the required package:

```bash
pip install -r requirements.txt
```

## Run the App

From this folder, run:

```bash
python app.py
```

Open the app in a browser:

```text
http://127.0.0.1:5000
```

The page should display a green background, red text, an italic `Flask Quickstart` heading, and a link to the Flask Quickstart documentation.
