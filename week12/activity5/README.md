# Week 12 Activity 5 - Flask BMI Calculator

This activity creates a Flask web application that calculates BMI using this formula:

```text
BMI = weight in kilograms / height in meters^2
```

## BMI Categories

- Underweight: less than 18.5
- Normal weight: 18.5 to 24.9
- Overweight: 25 to 29.9
- Obese: 30 or more

## Requirements

- Python 3.12 or later
- Flask

Install the required package:

```bash
pip install -r requirements.txt
```

## Run the App

From this folder, run:

```bash
python app.py
```

Open the app in a browser:

```text
http://127.0.0.1:5000
```

Enter weight in kilograms and height in meters, then click **Calculate BMI** to see the BMI score and category.
