# Zoo Login System

This is a simple Zoo Login System created using Python.

## Project Files

### `main.py`
Main program file.
- Takes username and password from the user
- Checks login
- Opens dashboard if login is correct

### `users.py`
Stores the admin username and password.

### `decorator.py`
Contains the decorator used in the project.

## Decorator

The project uses a decorator called `admin_only`.

The decorator checks whether the user is admin before allowing access to the dashboard.
