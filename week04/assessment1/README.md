This project focuses on building a relational database for a fintech application, developed as part of the MSE800-PSD course.

The system contains five main tables that support the money exchange process:

CUSTOMER: Holds user identity and contact information.
CURRENCY: Stores standard currency codes and related details.
ACCOUNT: Maintains customer account types and balances.
EMPLOYEE: Records staff involved in handling transactions.
TRANSACTION: Acts as the main record of exchanges, including amounts and exchange rates.
