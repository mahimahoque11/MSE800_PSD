# Activity 2: Land Measurement System

## Overview
This Python activity calculates the area and perimeter of rectangular land using a `RectangleLand` class.

## Contents
- `main.py`: Runs the menu/input flow and prints the land details.
- `rectangleland.py`: Defines the `RectangleLand` class with area, perimeter, and display methods.

## How to Run
From this folder, run:

```bash
python main.py
```

Then enter the land length and width when prompted.

## Requirements
- Python 3
